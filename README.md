# Bookmark Saver

A simple and clean web application to save and manage your favorite bookmarks. Built with HTML, CSS, and vanilla JavaScript.

## Features

- Add bookmarks with a name and URL
- Bookmarks are saved to localStorage (persists across sessions)
- Remove bookmarks with a single click
- URL validation ensures proper format (http:// or https://)
- Responsive and clean UI

## Demo

Simply open `index.html` in your browser to run the application locally.

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)

## How to Use

1. Enter a bookmark name in the "Bookmark Name" field
2. Enter the URL in the "Bookmark URL" field (must start with `http://` or `https://`)
3. Click "Add Bookmark" to save
4. Click "Remove" next to any bookmark to delete it
